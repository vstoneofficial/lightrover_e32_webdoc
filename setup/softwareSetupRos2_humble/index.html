    ソフトウェアセットアップ

    ライトローバー E32を動作させせるためには、ESP32-S3の開発環境の他にROS2 Humbleの動作する環境が必要です。
    以下の手順で、ROS2 Humbleの環境を構築していきましょう。
    なお本ドキュメントではUbuntu 22.04（実機PC）を想定して解説します。
    もし「Windowsで動作させたい」「専用のUbuntu PCが用意できない」という場合は、WindowsのWSL2上にUbuntu 22.04を構築して動作させることも可能です。
    WSL2のセットアップ方法についてはWSL2 Ubuntu 22.04をご参照ください。

    OSのセットアップと設定

    ROS2のセットアップや、ライトローバー E32を動作させるために必要な設定などを行います。

    ROS2のセットアップ

    ROS2 Humbleのインストール

    LinuxへROS2 Humbleをインストールします。
    基本的には以下のサイトの説明に沿って進めて行きます。
    ROS2 Documentation: Humble

    1. ロケールの設定
      UTF-8対応のロケールを設定します。
      ターミナルで以下のコマンドを実行してください。 

      sudo apt update && sudo apt install locales
sudo locale-gen en_US en_US.UTF-8
sudo update-locale LC_ALL=en_US.UTF-8 LANG=en_US.UTF-8
export LANG=en_US.UTF-8

    2. ROS2リポジトリの設定
      ROS2のリポジトリをソースリストに追加することで、インストールできるようにします。
      まず以下の2つのコマンドを実行してください。 

      sudo apt install software-properties-common
sudo add-apt-repository universe


      ターミナルで次の2つのコマンドを実行してください。 

      sudo apt update && sudo apt install curl -y
sudo curl -sSL https://raw.githubusercontent.com/ros/rosdistro/master/ros.key -o /usr/share/keyrings/ros-archive-keyring.gpg

      最後にsource listにリポジトリを追加します。 

      echo "deb [arch=$(dpkg --print-architecture) signed-by=/usr/share/keyrings/ros-archive-keyring.gpg] http://packages.ros.org/ros2/ubuntu $(. /etc/os-release && echo $UBUNTU_CODENAME) main" | sudo tee /etc/apt/sources.list.d/ros2.list > /dev/null


    3. ROS2 Humbleのインストール
      以下のコマンドを実行してROS2 Humbleをインストールします。 

      sudo apt update
sudo apt upgrade
sudo apt install ros-humble-desktop
sudo apt install ros-dev-tools
sudo rosdep init
rosdep update

    4. 環境変数の設定
      ターミナルからコマンドを呼び出して実行する際には、そのコマンドに対するパスが通っている必要があります。
      ターミナルを起動した際にROSへのパスが通るように設定を追加します。
      ターミナルを立ち上げて以下のコマンドを実行してください。 

      source /opt/ros/humble/setup.bash
echo "source /opt/ros/humble/setup.bash" >> ~/.bashrc

    以上で、ROS2 humbleのインストールは完了です。

    micro-ROS Agent のセットアップ

    1. micro-ROS Agent用のディレクトリを作成
      ターミナルを開き、下記のコマンドを実行しディレクトリを作成する。 

      mkdir -p ~/uros_ws/src

    2. micro-ROS Agentプロジェクトのクローン
      先ほど作ったディレクトリに移動しプロジェクトをクローンする。 

      cd ~/uros_ws/src
git clone -b $ROS_DISTRO https://github.com/micro-ROS/micro_ros_setup.git

    3. 関連ライブラリのインストールとプロジェクトのビルド
      下記のコマンドで関連ライブラリのインストール。その後プロジェクトをビルド。 

      cd ~/uros_ws
rosdep update && rosdep install --from-paths src --ignore-src -y
colcon build
source install/local_setup.bash
ros2 run micro_ros_setup create_agent_ws.sh
ros2 run micro_ros_setup build_agent.sh
source install/local_setup.bash

    lightrover_e32_ros2パッケージのインストール

    新たにワークスペースを作成しライトローバー E32をROS2から制御するためのパッケージ「lightrover_ros2」をセットアップしましょう。

    1. ワークスペースの作成 下記コマンドでROS 2用各種パッケージ用のワークスペースとなるフォルダを作成する。

      mkdir -p ~/ros2_ws/src

    2. Githubからlightrover_e32_rosパッケージのソースをクローン
      ターミナルを開き、下記のコマンドを実行する。

      cd ~/ros2_ws/src
git clone --recursive -b humble https://github.com/vstoneofficial/lightrover_e32_ros2.git
sudo apt update
sudo xargs -a ~/ros2_ws/src/lightrover_e32_ros2/packages.txt apt install -y

    3. ワークスペースのビルドとオーバーレイ
      下記のコマンドでワークスペースをビルド、その後ワークスペースをオーバーレイする。

      cd ~/ros2_ws
colcon build --symlink-install
source ~/ros2_ws/install/local_setup.bash

    4. シェルを起動時にワークスペースがオーバーレイされるように設定 

      echo "source ~/uros_ws/install/local_setup.bash" >> ~/.bashrc
echo "source ~/ros2_ws/install/local_setup.bash" >> ~/.bashrc

    これでlightrover_e32_ros2パッケージのインストールは完了です。

    IPアドレスの確認

    ターミナルで下記のコマンドを実行し、IPアドレスを確認してください。
    ESP32-S3の設定で利用します。 

    ip addr


    ROS2 Humbleの環境構築は完了です。
    続いてESP32-S3の開発環境の構築を実施してください。
