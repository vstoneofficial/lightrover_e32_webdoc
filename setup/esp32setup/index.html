    ソフトウェアセットアップ

    ライトローバー E32を動作させせるためには、ESP32-S3の開発環境が必要です。
    以下の手順で、ライトローバー E32を動作させるための環境を構築していきましょう。
    なお本ドキュメントではESP32-S3の開発環境はWindows 11に構築することを想定しています。

    ESP32開発環境のセットアップ

    Arduino IDEの環境整備

    1. Arduino IDE 2系のインストール
      Arduino IDEインストーラーダウンロードページからArduino IDE 2系のインストーラーをダウンロード。
      2026年10月8日現在、Arduino IDE 2.3.10での動作を確認しています。

    2. ボードマネージャーの設定
      Arduino IDEを起動、ツールバーから「ツール」→「ボード」→「ボードマネージャー」を選択。
      「esp32 by Espressif Systems」を検索し2.0.6をインストール。

    3. LDS.zipのダウンロード
      LDS gitページから「Code」→「Download ZIP」を選択し、LDS.zipをダウンロード。

    4. micro_ros_arduinoのダウンロード
      micro-ROS for Arduino Humbleから「Code」→「Download ZIP」を選択し、micro_ros_arduino-humble.zipをダウンロード。

    5. vs_wrc940_lightrover_e32.zipのダウンロード
      vs_wrc940_lightrover_e32から「Code」→「Download ZIP」を選択し、vs_wrc940_lightrover_e32.zipをダウンロード。

    6. Arduino IDEでライブラリの読み込み
      Arduino IDEのツールバーから「スケッチ」→「ライブラリをインクルード」→「.ZIP形式のライブラリをインストール」を選択。
      3.~5.でダウンロードしたzipファイルを選択しライブラリをインクルード。
      また、Arduino IDE画面左側のライブラリマネージャー（本のようなマーク）から、ArduinoJson（7.4.3）、NimBLE-Arduino（2.5.1）をインストール。

    7. ネットワーク、接続先IPアドレスの設定
      lightrover_e32_common.inoの102行目と103行目を接続するWi-FiのSSIDとパスワードに書き換えます。
      なおROS2を動作させるPCがつながっているネットーワークと同じものを設定してください。
      次にyy行目のIPアドレスをROS2を動作させているPCのIPアドレスに書き換えます。
      Ubuntuの場合、IPアドレスは下記のコマンドで確認できます。 

      ip addr

    8. lightrover_e32_common.inoの書き込み
      Arduino IDEのツールバーから「ファイル」→「スケッチ例」→「vs_wrc940」→「lightrover_e32_common」を選択。
      ツールバーから「ツール」→「ボード」→「esp32」→「ESP32S3 Dev Module」を選択。
      ツールバーから「ツール」の残りの設定を以下の通り修正。
      ・ポート : VS-WRC940を接続しているポート
      ・USB CDC on Booot : Enable
      ・Flash Size : 16MB(128Mb)
      ・Partition Scheme : 16M Flash (3MB APP/9.9MB FATFS)
      ・Upload Speed : 921600
      設定ができたら「書き込み」ボタン（右矢印マークのボタン）を押して、VS-WRC940にlightrover_e32_common.inoを書き込み。
      書き込み完了が表示されるまで待つ。

    以上でESP32-S3の開発環境の構築は完了です。


    以上で、ライトローバー E32をROS2で制御する準備が整いました。
